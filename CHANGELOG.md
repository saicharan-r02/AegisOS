- `LICENSE` file (MIT).

- War Room dashboard web interface: its React components, styles and mission-control client code, plus the committed built copy in `aegis_os/static/`. The Mission Control REST/WebSocket API is unchanged. See ADR 0013.
- The standalone `aegis_os/static/pr-pilot.html`, superseded by the React app in `web/`.
- `calculator.py` and its test suite `tests/unit/test_calculator.py`.
- Temporary `REFACTOR_PROGRESS.md`.

- **Adaptive Supervisor Reliability (`aegis_os/orchestration/adaptive.py`, `aegis_os/agents/cto/agent.py`)**: Added no-tools JSON fallback for `AegisCTO`, raised per-task iteration cap, and fixed false-positive `"ERROR:"` substring failures.

## [2.1.1] - 2026-11-15 (Mission Reliability & PR Pilot Patch)

### Added
- **PR Pilot Engine & UI**: Added automated GitHub issue-to-PR capability (`aegis_os/pr_pilot.py`), FastAPI endpoints (`/api/pr-pilot/analyze`, `/api/pr-pilot/execute`), and dedicated web interface (`aegis_os/static/pr-pilot.html` at `http://localhost:8000/pr-pilot`). Supports automated root-cause localization, surgical patch generation, verification, and interactive pull request guides.
- **Workspace Test Auditing**: Added `aegis_os/verification/workspace_audit.py` to detect and block deleted test functions, weakened assertions, or test file removal during autonomous missions.
- **Comprehensive Verification Suite**: Added `tests/unit/test_pr_pilot.py`, `tests/unit/test_agent_quality.py`, `tests/unit/test_api_real_missions.py`, `tests/unit/test_no_tool_nudge.py`, `tests/unit/test_repo_manager.py`, `tests/unit/test_reviewer_wiring.py`, and `tests/unit/test_workspace_audit.py`, expanding the unit test suite to **398 passing tests** (100% green, Python 3.11).

### Fixed
- **Python 3.11 Compatibility**: Replaced Python 3.12-only `Path.walk()` with standard `os.walk()` in `aegis_os/intelligence/repo_map.py`, `aegis_os/intelligence/search.py`, and `aegis_os/orchestration/worktree.py`.
- **Dynamic Plan Replanning**: Fixed `replan_failed_subgraph` in `aegis_os/orchestration/planner.py` to mark superseded tasks as `SKIPPED`, ensuring `is_all_completed()` evaluates correctly when replacement pivot tasks complete.
- **LoopGuard Reflection Headroom**: Relaxed stagnation threshold in `aegis_os/agents/base_agent.py` from 2 repeated turns to 3 turns, allowing agent reflection and self-correction before triggering hard escalation.
- **Tracer Span Ordering**: Fixed span query sorting in `aegis_os/tracing/tracer.py` to prioritize root spans (`ORDER BY (parent_span_id IS NOT NULL) ASC, started_at ASC`), ensuring deterministic parent-child hierarchy in trace telemetry.
- **Workspace Change Recognition**: Added git status inspection in `aegis_os/orchestration/adaptive.py` to ensure tasks modifying workspace files are recognized as completed even if task iterations are exhausted.
- Bounded agent prompt history and summarized pinned mission context to curb repeated-token growth.
- Escalated duplicate tool calls earlier and disabled raw model-output logging by default.
- Routed CTO plan-format retries through the normal step loop for accounting and telemetry.
- Distinguished `NO_TESTS_COLLECTED` from a passing test run and added one bounded acceptance-test bootstrap attempt.
- Prevented verification/finalization when planned implementation tasks remain incomplete.
- Skipped the full Ops health-check agent for static/documentation-only diffs while retaining runtime/build/deployment checks when relevant.
- Bounded security and operations agent call loops.
- Bounded resource limits: role context 48,000 tokens, tool output 1,800 tokens, completion 2,048 tokens; mission token (1,500,000 tokens) and wall-clock limits (7,200 s) configured in aegis.toml (no dollar cap; max_cost_usd = 0 means unlimited).

### Changed
- Reworked developer, QA, and CTO instructions to be task-aware, avoid repetitive exploration, and use compact plans.
- Updated `.env.example` with an NVIDIA NIM placeholder and ignored generated workspaces/debug traces.
- Documented the agent operating model, mission example, known limitations, and validation status.

### Security
- Excluded local `.env`, Git metadata, databases, generated workspaces, and raw traces from the distributable source archive. Rotate any credential previously present in a shared archive or repository history.

## [2.1.0] - 2026-11-12 (Stability & Hardening Release)

### Fixed
- **Security scanners on Windows**: Replaced `.exe` scanner invocations (`bandit.exe`, `detect-secrets.exe`, `pip-audit.exe`) with `python -m <module>` using `importlib.util.find_spec()` to work around Windows Application Control Policy that blocks `.exe` binaries in virtual environment `Scripts/` directories.
- **`.env` loading**: Added `load_dotenv()` to `aegis_os/cli/main.py` startup so `NVIDIA_API_KEY` and other secrets are always loaded before CLI commands execute.
- **Doctor API key detection**: `aegis doctor` now reads LLM keys from both `os.getenv()` and `LLMConfig()` (pydantic-settings), correctly reporting configured NVIDIA NIM keys.
- **Ruff lint (90 errors → 0)**: Fixed import ordering, E402 (imports after code), UP007 (deprecated `Union` type hints), F821 (undefined `ToolResult` in registry), and unused variable assignments across the codebase.
- **Frontend static component warnings**: Converted nested React components in `App.tsx` from JSX component tags to render functions (`renderSidebar`, `renderTopbar`, `renderDashboardPage`, etc.) eliminating oxlint `static-components` warnings.
- **Frontend provider sync**: Default provider changed from `groq` to `nvidia`; provider dropdown restricted to NVIDIA NIM (the only supported provider).
- **Stale static assets**: Rebuilt frontend (`npm run build`) and replaced stale `index-BancVqMk.js` / `index-DDIbYTkB.css` with fresh `index-C16pQFwh.css` / `index-CggcdwVI.js`.

### Changed
- **Model fallback chains**: All agent roles now have two-tier fallbacks (primary → fast-flash → lightweight-7b) for improved resilience during NVIDIA NIM cold-starts or quota limits. Added `nv-mistralai/mistral-nemo-12b-instruct` and `mistralai/mistral-7b-instruct-v0.3` as second-tier fallbacks.
- **Retry configuration**: Increased `max_retries` from 2 to 3 and `retry_max_seconds` from 8s to 16s to handle NVIDIA NIM API latency spikes.
- **Ruff exclusions**: Added `eval/tasks`, `.venv`, `node_modules`, `web` to ruff `exclude` list (benchmark fixtures intentionally use non-standard style).

### Removed
- Diagnostic/scratch scripts left from development: `aegis_raw_debug.log`, `diag_groq.py`, `diag_llm.py`, `diag_router.py`, `model.py`, `nvidia.py`, `nvidia_model_test_results.csv`, `nvidia_tool_test.py`, `nvidia_working_models.txt`, `test_nvidia_tools.py`, `full_master_prompt.md`, `master_prompt_extracted.txt`, `scratch/` directory.
- Duplicate test file `tests/test_calculator.py` (kept canonical `tests/unit/test_calculator.py`).
- Stale web files: `web/calculator.py`, `web/tests/`, `web/.aegis/`, `web/src/App.css`.

## [2.0.0] - 2026-10-21 (Production Release)

### Added
- **Multi-Provider LLM Router**: Seamless fallback chains across Groq, OpenAI, Anthropic, Gemini, and local OpenAI-compatible endpoints with native function calling and token budgets (superseded in 2.1.0: NVIDIA NIM is the only supported provider).
- **Docker Sandboxing**: Default containerized execution with dropped capabilities, read-only root FS, non-root user, and disabled network access.
- **3-Tier CommandPolicy**: Deterministic in-code command authorization (`auto_allow`, `require_approval`, `deny`).
- **Codebase Intelligence**: Multi-language PageRank `RepoMap`, pure-Python Okapi BM25 search index, and read-only `AegisExplorer` sub-agent.
- **Dynamic DAG Planning & Adaptive Supervisor**: Replaced linear waterfall with dynamic task DAG, parallel git worktree isolation, `FailureLedger` feedback, and `HardInvariants`.
- **Anti-Gaming Verification**: `BaselineVerifier`, AST `TestIntegrityGuard` (blocking test deletion, skip markers, assertion weakening), independent `AegisReviewer`, and `--tdd` Red→Green coordinator (TDDCoordinator ships as a library component; no CLI flag is wired).
- **Cross-Mission Memory**: SQLite episodic mission store, convention learning, and BM25 experience retrieval.
- **True Filesystem Rollback & Time-Travel**: `ShadowBranchManager` with git shadow commits & tags, dual checkpointing with SQLite, `aegis rollback`, and `aegis rewind`.
- **Structured Tracing & Replay**: Span-level latency, token, and cost tracking with `SecretRedactor`, JSONL export, and `aegis replay` (zero LLM calls).
- **Hardened Mission Control API & War Room Dashboard**: Live approvals inbox, side-by-side diff modal, span trace tree, acceptance checklist, and memory browser.
- **Autonomy Modes & Integrations**: `--mode plan|supervised|auto`, `aegis chat` pairing shell, GitHub issue URL ingestion, automated PR generation, and MCP tool client.
- **Scientific Benchmarking**: Expanded to 34 golden tasks across 6 disciplines with ablation analysis in `docs/RESULTS.md`.
- **Pre-Flight System Diagnostics**: `aegis doctor` and `aegis --version`.

### Changed
- Default strategy upgraded to `--strategy adaptive` with backward-compatible `--strategy waterfall`.
- Subprocess execution moved behind explicit `--unsafe-local` flag.

### Fixed
- Fixed Windows SQLite file-locking `PermissionError` (WinError 32) during rollback filesystem resets.
- Fixed unclosed database connections in multi-department orchestrator.
